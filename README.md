# IT-License-Utilization-Dashboard

## Project Summary
End-to-end IT asset management analysis tracking 500+ software 
licenses across 8 departments to identify cost reduction 
opportunities and renewal risk.

## Live Dashboard
[View on Tableau Public](paste your tableau public link here)

## Tools Used
- SQL (SQLite / DB Browser)
- Tableau Public
- Excel (Sensitivity Analysis / What-If Scenarios)
- Python (pandas) — dataset generation
- PowerPoint — Executive Summary

## Key Findings
- 25% of licenses operating below 40% utilization threshold
- 22% projected OpEx savings identified
- ~100 assets flagged for renewal within 90 days
- Top 3 vendors (SAP, Oracle, Salesforce) = 68% of total spend
